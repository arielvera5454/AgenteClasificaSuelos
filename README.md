Agente Clasificador de Compactación de Suelos 🚜🌱Este proyecto consiste en un sistema de inteligencia artificial desarrollado desde cero (sin librerías de ML externas) para clasificar el nivel de compactación del suelo. Utiliza dos modelos de aprendizaje supervisado: k-Nearest Neighbors (k-NN) y un Árbol de Decisión (ID3).El sistema predice la compactación basada en el Cone Index (Índice de Cono), un parámetro crítico en agronomía para evaluar la salud del suelo y el potencial de crecimiento radicular.🚀 Características PrincipalesDoble Motor de Inferencia: Comparación en tiempo real entre un modelo basado en distancias (k-NN) y uno basado en reglas de decisión (ID3).Procesamiento de Datos Robusto: Implementación manual de normalización de datos y discretización de variables.Validación Estadística Real: Uso de K-Fold Cross-Validation (5 pliegues) para garantizar que la precisión sea estadísticamente significativa.Zero-Library Dependencies: Implementación pura en Python utilizando solo math, csv, os y random.🛠️ Arquitectura y Metodología Técnica1. Tratamiento de Datos (Ingeniería de Características)Se aplicó un filtrado estricto para evitar la Fuga de Información (Data Leakage). Se eliminaron variables administrativas (Plot, Field, Block, Tx) que no aportan información física, obligando al modelo a aprender patrones reales del suelo (tráfico, profundidad, residuos).2. Optimización por ModeloPara que los algoritmos funcionen correctamente con sus bases matemáticas, los datos se procesan de dos formas distintas:Para k-NN (Escalamiento Min-Max): Se normalizan las variables al rango $[0, 1]$. Esto evita que variables con números grandes (como los residuos) opaquen a variables binarias (como el tráfico de maquinaria).Para Árbol de Decisión (Binning/Discretización): Dado que el algoritmo ID3 trabaja con entropía categórica, las variables continuas (profundidad) se agrupan en rangos: Superficial, Media y Profunda. Esto evita el sobreajuste (overfitting).3. Evaluación RobustaEn lugar de un simple entrenamiento/prueba, el sistema divide el dataset en 5 bloques aleatorios (Folds). Entrena 5 veces y promedia los resultados.📁 Estructura del Proyectomain.py: Punto de entrada del programa y orquestador de la validación cruzada.dataset.py: Cargador de datos con lógica de normalización y limpieza.decision_tree.py: Implementación del algoritmo ID3 (Entropía y Ganancia de Información).knn.py: Implementación del clasificador k-NN basado en distancia euclidiana.validator.py: Capa de validación para asegurar entradas de usuario correctas.evaluator.py: Herramientas para medir la precisión del modelo.test_predict.py: Script de prueba automática con rutas dinámicas.📋 Requisitos e InstalaciónAsegúrate de tener instalado Python 3.x.Clona o descarga este repositorio.Coloca el archivo de datos Field 70-71 ConeIndex_BulkDensityDepths_2021_0.csv en la carpeta raíz del proyecto.No se requieren librerías adicionales (como Pandas o Scikit-Learn).💻 Uso del SistemaEjecución PrincipalBashpython main.py
El menú te permitirá:Ver Validación Estadística: Ejecuta el K-Fold y muestra la precisión promedio real de ambos modelos.Predecir: Ingresar manualmente los datos de un nuevo perfil de suelo para obtener un diagnóstico.Prueba AutomáticaBashpython test_predict.py
Este script simula una sesión de usuario completa para verificar que todos los módulos estén sincronizados correctamente.📊 Criterios de Clasificación (Objetivo)El nivel de compactación se define según el Cone Index (MPa):BAJA: < 1.0 MPa (Suelo óptimo para crecimiento).MEDIA: 1.0 - 2.0 MPa (Resistencia moderada).ALTA: > 2.0 MPa (Límite crítico agronómico donde el crecimiento de raíces se detiene).
